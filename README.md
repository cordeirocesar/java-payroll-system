# ☕ Java Payroll System (Study Project)

This project is a simple Java console application built as a practical exercise to practice core Object-Oriented Programming (OOP) concepts and improve my Java skills.

## 🎯 Purpose

I created this project to practice:
- **Abstraction & Inheritance:** Structuring class hierarchies (`Person` ➔ `Employee` ➔ Specific Roles).
- **Polymorphism:** Calculating different bonus rates based on employee roles.
- **Encapsulation:** Managing private attributes with getters and setters.
- **Collections & Loops:** Iterating over lists to process employee data and display payroll summaries.

## 💻 How It Works

The system calculates total earnings based on role bonuses:
- **Product Manager:** Base Salary + 20%
- **Developer:** Base Salary + 15%
- **DevOps Engineer:** Base Salary + 10%

It then prints individual employee reports along with the total employee count and total basic salary expense.
